PATCH AND BUILD NOTES
==================================================

Kernel cfg80211 compatibility patches:
  rtl8189fs-kernel-6.12.patch
  rtl8189fs-kernel-6.18.patch

Kernel 6.12:
  Three cfg80211 key callbacks changed from
  enum nl80211_key_type pairwise to bool pairwise
  for kernel version 6.12 and newer.

Kernel 6.18:
  Additional cfg80211 API compatibility changes
  are included in the 6.18 patch.

Bookworm build:
  Original kernel headers contained a modpost binary
  requiring GLIBC 2.38.
  Rebuilt modpost using system GCC 12.2.0.
  This workaround may be needed on Debian Bookworm
  with GLIBC 2.36.

Trixie build:
  Kernel headers used:
  /usr/src/linux-headers-6.18.59-ophub
  No modpost GLIBC workaround was required.

IMPORTANT:
  Always use the module matching the target kernel.
  Modules built for different kernel versions are
  not interchangeable.

  Cross-distribution tests do not imply compatibility
  with other kernel builds.
